# Candra privacy policy

The policy has moved to Candra's own pages:

- **Android:** https://suryamajapahit.com/candra/privacy/android
- **iPhone and iPad:** https://suryamajapahit.com/candra/privacy/ios

In short: Candra has no accounts, no ads, no analytics and no trackers.
Everything you write stays on your device, and leaves it only when you
send it yourself.

Support: https://suryamajapahit.com/candra/support
